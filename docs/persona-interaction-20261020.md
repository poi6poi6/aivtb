# 2026-10-20 人格互动优化

对话策略根据当前话题、用户纠正和已送达的回复调整后续回应。

## 对话中的变化

| 场景 | 现在的处理 |
|---|---|
| 平时喜欢建议，今天只想说说 | 当前明确需求优先；“先听我说，别给建议”切到倾听，“现在给我一点建议”再切到具体办法，也支持一起梳理和轻松聊天 |
| 倾诉后下一句没有情绪词 | 同一账号继续沿用认真回应的分寸，不因原来的 25 秒演出缓冲过去而突然开玩笑；其他账号插话不清掉自己的状态 |
| 主动想轻松一下，随后又认真求助 | 明确请求轻松聊天时允许温和幽默；后来重新表达困扰时收起轻松模式 |
| 指出理解偏差、事实错误、表达不合适或观点不同 | 区分修正类型，让本轮及接下来的回应实际调整；首次必要时简短承认，后续不反复道歉；事实仍须核对，不盲目同意 |
| 说“谢谢，但你说得不对” | 礼貌措辞不会盖过更正；事实、需求、审美与表达调整不降低信任，也不让全局人格变冷 |
| 说“你刚才的回答很敷衍” | 保留真实负反馈，促进更清楚的表达；不把其他人的评价、引用、否定或普通“谢谢”当作回复质量评分 |
| 一起制定周末安排 | 只从已完整说出的内容建立共同安排，记录下一步及已经谈到的内容；重复“之后再看”不算实际推进，一句“好”不算完成 |
| 选好了、取消或换话题 | 明确完成或结束相关安排后收尾，迟到的旧语音片段不会恢复旧待办；不再给无关话题插入旧安排 |
| 相处更熟悉 | 少重复问已确认的背景，相关且有证据时自然接续共同话题；保留自身判断，不编造共同经历、新爱好或亲密关系 |

## 状态与执行

- `brain/dialogue_policy.py` 用本地规则生成固定沟通提示，按稳定账号身份隔离，不额外调用模型，也不将用户原文升级成系统指令。
- 临时互动状态最多保留每人最近 12 个有效回应回合；闲置 15 分钟后失效，最多保留 128 个账号。修正提示覆盖当前与后续两轮，明确收尾会提前清除。
- `brain/persona.py` 将同一策略接入普通回复、流式回复、口播规划与表情动作；预览提示和计算预算不推进状态。
- `brain/character_behavior.py` 保留全场短暂情绪过渡，同时允许当前账号的话题持续性和明确结束控制实际演出。
- `brain/conversation.py` 根据播放完成回执更新共同安排，支持进展、完成、取消、撤回和按账号遗忘。保留原有公开弹幕上下文；新增共同安排提示及完成动作按账号隔离。
- `brain/personality_evolution.py` 慢速学习长期偏好与明确反馈，当前需求始终优先。既有历史状态保留，本次没有批量重写旧关系数据。
- `brain/main.py` 在语音撤回、更正及记忆管理变更时同步清理临时互动状态；遗忘时间屏障阻止尚未处理的旧输入重新建立已清理的状态。

这些规则有意保持保守，不会从“唉”“算了”等含混短句猜测完整情绪或需求。复杂隐喻和隐含话题切换仍取决于模型结合对话理解；共同进展仅指对话中已交付的内容，不代表后台任务实际执行完成。临时互动状态重启后清空。

## 生效与试聊

重启主控服务后生效，不需要更改角色卡或重新训练模型。本次没有重启正在运行的服务，也未进行真实模型、TTS 或麦克风试听。

可以用下面几组多轮对话检查实际措辞；预期是行为方向，不要求逐字输出固定台词。

1. “我有点难过，先听我说，别给建议。”→“他后来还是没有回复。”→“现在给我一点建议。”：先具体承接，再直接给一个实际下一步。
2. “你刚才理解错了，我不是这个意思。”→补充真正的意思：简短修正，后续不再沿用错误理解，不反复道歉。
3. “一起安排周末吧。”→选定地点→讨论时间→“好，就这么定。”：承接进展，最后自然收尾。
4. “换个话题，聊聊你喜欢的玫瑰。”：转入新话题，不继续追问刚才的困扰或待办。
5. “我不这么看。”：允许保留各自看法，有必要时说明依据，不用附和表示亲近。
