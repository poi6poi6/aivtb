# 助手 Minecraft 本机测试

国际 Java 1.20.1，Node 24，Mineflayer 4.39.0、pathfinder 2.4.5。游戏和机器人版本固定为 1.20.1。

## 首次启动

准备 Java 版 1.20.1 服务端，将 server.jar 放入 `data/minecraft/server/`。用 Java 17 首次执行 `java -jar server.jar nogui` 生成配置文件。启动器会查找官方 Windows 游戏启动器自带的 Java 17，若使用独立 Java，也可在该目录直接启动服务端。

在该目录的 `server.properties` 中设置 `server-ip=127.0.0.1` 和 `server-port=25565`。仅限本机离线机器人测试时使用 `online-mode=false` 并保持回环地址。在项目根目录运行 `npm --prefix minecraft ci` 安装机器人依赖。

1. 阅读 https://www.minecraft.net/eula 。同意后将 `data/minecraft/server/eula.txt` 的 `eula=false` 改为 `eula=true`。脚本不会自动同意条款。
2. 在项目目录运行 `.\启动.cmd -Action minecraft-start`。查看 `data/minecraft/server/console.log`，出现 `Done` 才算启动成功。
3. 用 1.20.1 客户端打开多人游戏，直接连接 `127.0.0.1:25565`。
4. 启动原有角色主服务，在本机打开 `http://127.0.0.1:8080/minecraft`，点击「连接游戏」。看到机器人 加入后，点击「自主开局」。角色主界面负责语音输出。

服务端使用全新独立存档 （存档名见本地 `server.properties` 的 `level-name`）。只绑定 127.0.0.1；offline-mode 仅用于本机机器人和观看客户端，不应改成公网监听。没有开启公网映射。

## 当前能力与边界

- 基于游戏协议读取位置、血量、饥饿值、背包，不使用截图猜操作结果。
- 手动观察、靠近指定玩家、挖原木并拾取、合成木板、合成工作台。
- 保留「自主开局」小任务；新增「开始 / 继续通关」长期目标。通关模块是实验版，尚未进真实服务器验证全流程，不能视为已具备稳定独立通关能力。
- 原木只搜索 24 格；寻路不会自行破坏方块或搭桥。如果出生点没树，先带她靠近树林。采木应在新测试世界验证，模块不区分人工建筑中的原木。
- 每个任务最长 60 秒。暂停使未完成任务失效，不再下发下一项操作；已经发送到服务端的单次挖掘/合成可能仍会完成。
- 通关计划优先进食和回血，战斗血量低于等于 8 停止攻击。测试服改为普通难度，以便生成通关所需敌对生物。
- 只有游戏回执进入主程序的事件队列；是否解说仍由现有仲裁和语音系统决定。控制请求提交成功不等于动作成功。
- 不自动启动 TTS/角色主服务，不自动连接游戏、不消费 LLM 规划额度。规划目前为可检查的规则与真实配方依赖，尚未接入弹幕任务或开放式 LLM 规划。

## 实验性通关计划

`minecraft/campaign.js` 根据真实背包、维度、血量重新选择下一项；阶段不是只增不减的勾选表，丢失装备后会重新准备。

1. 生存与据点：获取动物食物、熔炉烹饪、吃饭与回血、记录据点坐标。据点坐标不是已建成房屋，也不是已设置重生床。
2. 铁器与补给：通过 1.20.1 真实配方补材料，放置工作台和熔炉，熔炼铁锭，制作并装备铁甲、盾、武器、弓箭。
3. 下界准备：阶梯式勘探矿物、准备钻石镐、采集黑曜石、装水、搭建并点燃黑曜石门。搭建中断会保存框架坐标。
4. 下界收集：记录返程门、寻找并攻击烈焰人和末影人、拾取并重新核验材料数量。缺少目标时沿可达地面探索，不调用作弊定位命令。
5. 寻找要塞：合成末影之眼，记录投掷实体轨迹、双线估算方位、分段接近与向下探路；只有实际发现框架并观察到门方块后才认定打开成功。
6. 末地挑战：有支撑的搭路与阶梯、拆铁栏、远距离射击水晶、接近或射击末影龙。射箭采用简化弹道补偿，需要实机校准。

### 恢复与证据

- 通关文件：`data/minecraft/campaign.json`。原子写入最近步骤、失败次数、据点/门/死亡位置和最近背包。根据本地世界目录的创建时间隔离换世界后的进度；检测到不同世界会备份旧文件。手动替换存档且保留目录创建时间时需先备份并移走通关文件。
- 同一步连续失败 3 次暂停，允许处理环境后点击「处理卡点后重试」。失败期间尝试短距离换路或安全阶梯，不把失败说成成功。
- 通关运行中死亡会保存位置，3 秒后请求重生，确认出生后再重新规划。10 分钟内第 3 次死亡停止自动重生；暂停、断开会取消待执行重生。
- 仅对 4 分钟内、48 格内、同维度且血量足够的死亡地点尝试拾取。其他情形重新备装，避免盲目冲回危险区域。
- 单步最长 90 秒，替代路线最长 45 秒；单轮最多 400 步/30 分钟，达到上限保存并等待继续。
- 通关完成必须收到末地的末影龙 `entityDead` 事件，同时角色处于生存模式且本次连接参与过龙战。实体卸载、聊天、LLM 文本均不能触发完成。这能确认参与的战斗结束，不能证明最后一击或全程单人击杀。

### 尚需实机验证

复杂地形的长距离可达性、深层矿物搜索、食物供应、下界要塞探索、末影人战斗、要塞垂直定位、末地出生平台出路、登塔与箭矢命中率均为实验能力。实现了相应操作路径，不代表已经成功跑过。遇到无法证明安全或未加载的地形会暂停；目前没有完整建筑、自动农场、自动存箱、睡床和成熟的地形路线规划。

服务端 EULA 仍未确认，因此此轮只运行配方/规划/回执/取消/进程与网页测试，没有启动游戏服务器或进行真实通关。

## 直播与停止

### 本机第一视角

独立游戏控制台：运行 `.venv/Scripts/python.exe tools/run_minecraft_test.py`，打开 `http://127.0.0.1:8084/minecraft`。无需启动 LLM 或 TTS。连接机器人后打开 `http://127.0.0.1:3007/`，prismarine-viewer 以第一视角重建她所在世界，镜头同步位置与朝向。仅监听本机；断开机器人时关闭观看服务。网页并非原版客户端录像，不提供完整 HUD、原版光影或游戏声音。

可以通过原生 Minecraft 客户端观看机器人，也可以使用上述第一视角网页。直播可添加该网页为浏览器素材，并保留原有 Live2D 素材；第一视角网页本身没有游戏声音。

控制台「暂停动作」停止当前任务，「断开连接」让机器人退出。关闭角色主程序也会回收机器人子进程。

运行 `.\启动.cmd -Action minecraft-stop` 会向服务端发出 `stop`，正常保存世界后退出。不要在世界保存期间强制结束 Java。

日志：`data/minecraft/server/console.log`、`wrapper-error.log`、`data/minecraft/bot-error.log`。
