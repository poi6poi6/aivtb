# 随时间更新的聊天素材

在 `/companion` 的“最近可以聊什么”管理公开热点。Astra 通过本机 Codex 的 ChatGPT 套餐执行实时 web search，当前主人格继续负责回复。首次搜索输入只有分类和当前时间；必要时用本次公开候选补核来源。不包含私人聊天、记忆、日记或人设。

默认开启，分类为二次元与游戏、热梗与网络文化、金融与消费现象，每 6 小时在系统空闲时尝试更新。可关闭、选择分类或把周期改为 2–24 小时；“现在更新素材”会提交一次固定分类查询，不接收任意搜索指令。只有本机主服务运行时会更新，关闭应用后不会在 Codex 里另建定时任务。

一次至多 6 条素材，缓存至多 12 条。只接受近期来源，每条保留标题、摘要、讨论角度、公开日期与来源链接；缓存最多保留 24 小时，并同时检查来源的新鲜度。过期资料不会继续当作当前热点。查不到、搜索失败或额度不足时如实显示；不能用模型记忆冒充联网结果。

自动刷新每天最多 4 次，包含手动在内每天最多 8 次；重复点击不会并发查询。失败会退避，尝试时间和计数持久化，重启不能绕开额度。此上限是请求次数限制，并不是套餐 token 用量保证；实际查询前还会检查登录、Astra 权限与剩余额度。不会切换其他模型、购买额度或改用 API Key。

聊天只在询问热点、与素材相关，或直播导演本来就允许开始新话题时使用素材。已有话题、明确结束话题、视频播放与塔罗环节继续遵循原有流程。更新本身不说话、不发送 QQ 消息、不发动态，不自动开启直播导演。QQ 私聊和群聊只借用相同的公开素材，不借用其他用户的聊天记录。

政治相关作为排除项：时政、政治人物、政党、战争、地缘政治、政治隐喻和谐音梗，以及涉及这些内容的金融事件都舍弃。不确定是否涉及政治的素材也舍弃。金融只聊财报、公司、行业与消费现象，不给荐股、买卖点或收益承诺。选题采用模型语义筛选、限定分类和本地规则校验；主人格提示与输出检查同时生效。热点回复完整检查后再开始播报。这些检查会持续拦截风险内容，但自动分类不等同于无漏判的人工审核。

来源和摘要属于外部资料，不能变成系统指令。Astra 使用隔离临时目录、只读沙箱，关闭 shell、文件修改、浏览器操作、应用、MCP、插件与记忆；只允许内置 web search。每条来源必须有本次任务打开网页的回执，不能只拿搜索摘要或模型自报链接作为完成依据。候选缺少来源打开回执时，最多补核一次、至多 4 个来源，仍在同一个 180 秒总检索期限内；补核不能增加新话题或悄悄更换来源。失败就舍弃，不无限重试。聊天使用热点资料时不再重复走旧的通用搜索引擎。

实现入口：`brain/astra_trends.py`（套餐搜索）、`brain/trending_topics.py`（校验、缓存、调度）、`brain/trending_web.py`（本机控制）、`brain/runtime_services.py`（生命周期与聊天衔接）。

协议参考：[OpenAI Docs：实时 web search](https://learn.chatgpt.com/docs/web-search)、[Codex App Server 的搜索事件](https://learn.chatgpt.com/docs/app-server)。
