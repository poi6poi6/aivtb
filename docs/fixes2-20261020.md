# 2026-10-20 第二轮复查修复记录

本轮修复第二次项目检查确认的 6 项问题。第一轮的 8 项修复与依赖维护保留在[第一轮记录](fixes-20261020.md)。

| 问题 | 修复后的行为 | 主要文件 |
|---|---|---|
| 复合命令隐藏测试失败 | 无法确定测试范围的执行记录阻止应用；可识别的 Python 测试仍须有成功摘要，不能用最后一条输出命令的成功退出码掩盖失败；较小范围的成功测试不能覆盖完整范围失败；纯字面量报告引用不计作测试 | `brain/code_review.py`、`brain/agent_tasks.py` |
| 连续消息中的偏好纠正没有进入长期记忆 | 聚合消息携带原始账号、文本、时间与消息标识，贯穿语音和播放确认；同账号输入按原始时间批量处理，旧证据不会在后续语音片段中重新覆盖纠正；每条输入分别接受隐私、身份及遗忘屏障检查 | `brain/arbiter.py`、`brain/speech_pipeline.py`、`brain/conversation.py`、`brain/autobiographical_memory.py` |
| 暂停期间收到播放开始确认，恢复后立即超时 | 将开始时钟固定在暂停时刻，恢复时排除暂停时长；播放状态和演练收到一次有效开始确认，重复回执不会重置时钟 | `brain/playback.py`、`brain/webui.py` |
| HTTP 探测挂起时 WebSocket 不再重连 | 断线后立即独立计时重试；下一次连接会取消旧探测，过期回调不会影响新连接；有效的 403 邀请过期响应仍会停止重试 | `brain/static/index.html` |
| 音乐历史达到 100 条时删除尚未完成的任务 | 优先裁剪最旧终态记录，保留未完成任务及后台工作持有的对象引用；重启后可以继续查询、去重和取消；20 个活动任务上限继续有效 | `brain/music_requests.py` |
| 已完成的自动改进目标占满容量，无法继续提交 | 满 100 条时先将已完成且未被当前活动任务引用的目标写入归档，再接收新目标；保留完整目标、部署任务标识和重复提交计数；归档失败不会删除目标 | `brain/self_upgrade.py` |

自动改进归档位于 `data/self-upgrade/archive/<目标标识>.json`，保留首次归档时间。阻塞中的目标仍留在工作列表中，可继续使用原有独立验收入口；如果 100 条全部未完成，仍明确提示先处理已有任务。

新增回归覆盖实际语音流水线与播放回执、并发分段记忆、跨账号隔离、遗忘及编辑期间的迟到写入、暂停与恢复时钟、挂起探测与过期回调、历史裁剪后的后台写回，以及归档失败、重启和部署追溯。

审核回归实际执行 PowerShell 包装的 Python 失败测试，以及先输出 `PASS` 再断言失败的 Node 脚本，确认两者即使被末尾输出命令掩盖退出码也不会通过审核。报告分类另有真实 `Set-Content` 写入测试；插值、代码块、多命令和 shell 包装继续保守阻断。
