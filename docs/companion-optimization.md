# 2026-09-20 陪伴与互动优化

## 2026-10-29：两批六项陪伴能力

主控页增加“陪伴能力”入口 `/companion`。由 `RuntimeServices` 管理
`CompanionFeatures` 的生命周期，沿用主人格 DeepSeek、现有上下文预算与交付回执。
本轮是项目原生实现这些能力；不需要另启动六个 DSH 插件进程。

图片理解是经本机登录调用云端 Astra，不是在本机运行模型。仅把本次图片和问题发送给它，
不附带主人格、私人日记或历史聊天。单张图片最大 5 MiB，支持 PNG/JPEG/GIF/WebP；
动图只依据能读到的静态画面。临时图片在请求结束、失败或取消后清理，线程不持久保存。
视觉结果仅接受完整的结构化最终回答；OCR 文字作为不可信资料，不是给人格的指令。
登录/权限、连接或超时失败会如实反馈，不切换到付费 API 或另一模型。

Windows 从桌面启动时也会自动查找本机 Codex 安装目录，不要求把 Codex 加入系统 PATH。
页面检测与实际看图使用同一套客户端定位逻辑；自定义安装仍可通过
`agent_tasks.codex_command` 指定可执行文件，明确指定的路径失效时不会自动换客户端。

QQ 图片下载仅允许指定腾讯 CDN 的 HTTPS 地址，不跟随重定向；图片回执使用同一条消息租约。
上传失败且尚未发送可退回文字，发送结果未知时不自动补发，避免重复。网页与管理接口只供
本机主控，写入检查同源；公开测试模式没有这些私人能力。

日记记录的是实际对话摘录，不把模型承诺写成已经发生的经历。删除/修订记忆同步清理相关
私人日记并设置迟到回执屏障；已安排日程保留。提醒在入队前持久认领，播放回执确认完成；
重启时无法确认的发送转为未知状态，不自动重发。直播/展示输出接入时暂停私人主动提醒。
语音日程和日记还需要转写确认，或正常进入下一轮；纠错、撤回会丢弃原版待确认记录。
日程改期、取消、关闭跟进或切到 OBS/展示输出时，会停止相应的生成、合成和播放。

数据目录为 `data/companion/`，包含设置、图库索引、私人日记及日程。源码更新后需要重新启动
主服务，再刷新主控页。不要用公开直播画面展示私人管理页。

## 日常对话

- 陪伴、情绪表达、询问个人记忆等明确私聊不再仅因问号而联网。明确“查一下、搜索、核实”仍可触发查资料；天气、新闻和事实问题保留搜索。
- 搜索采用五秒整次等待上限，失败如实降级。最多保留128项内存缓存。分类仍为本地规则，含蓄表达可能误判，可以明确说“查一下”。
- 首个自然逗号前达到24字时先送去合成，表情动作标签不计入长度，也不会在标签中间拆分。此次提前拆分额外获得一个传输段，不挤占后续回答预算。
- `llm.first_clause_chars: 0` 可关闭提前分段。音频仍是逐段WAV，首段更短不保证所有句子都更快，也未替换声音模型。

## 语音操作

“设置与调试”新增“接话节奏”：自然、快一点、多等一会儿。未说完的连接词仍会多等一会儿；“我说完了”等明确结束语可以更快提交。“等等，我不是这个意思”等明确插话只触发一次中断。

在“常用名字”中填写需要核对的称呼，多个名字用逗号分隔。当识别结果与常用名字相差一个字时，停止自动提交并提示核对。它不自动替换名字，不声称识别置信度提高。设置只保存在当前浏览器。

仍需点击麦克风才能在她说话时插话。本轮没有开启同时录音播放，也没有新增音频级VAD、回声消除或独立ASR服务。

## 记忆

- 新增本地同义概念重排，涵盖饮品、睡眠、食物、工作、学习、兴趣等常见主题。例：“我喝咖啡容易睡不着”可作为用户自述保存，在“晚上喝点什么好”时成为候选线索。
- 重排只处理原本可见且有效的记忆，保留否定、用户原意、来源和有效期，不把用户自述转换成通用因果结论。
- 已遗忘、过期、被纠正的旧版本不重新参与召回。`selective_memory.semantic_recall: false` 可关闭此重排。
- 具有平台身份编号的新观众记忆按来源和编号隔离；播放回执继续传递该编号，同昵称不合并。旧版只有昵称的记忆不会自动认领给带平台编号的账号，可由本人重新陈述。语音/一对一未提供平台编号时仍沿用原称呼规则。
- 本轮是有限本地语义词表，未安装向量模型或调用额外嵌入API；开放领域同义改写仍可能漏召回。

## 两阶段绘画

1. 新建逐笔绘画任务先准备草稿。任务卡片点击“查看草稿、修改或继续上色”。
2. 在画布输入修改要求，点“预览修改”，核对后点“确认这次修改”，产生关联草稿修订。旧文件保留。
3. 草稿满意后，点“继续上色与细节”；可以同时填写“眼睛小一点、背景换成夜景”等要求，预览确认后生成完整成稿。
4. 聊天也支持“继续上色”或“草稿可以，继续上色，换成夜景”，随后确认修改任务。观众请求仍遵循归属与主播批准规则。

每个阶段各自完整生成后才可播放。执行器会取得经过验证的前阶段笔画数据；新版本须保持画布尺寸。修改可能需要重画部分笔画，本轮不是逐笔实时生成，也没有视觉模型回看画布的反馈循环。

画布和“直播纯画布”从同一个后台服务获取时间线。暂停、重画和调速在各页面同步；主界面8080与独立任务台8085连接同一后台时也共享。纯画布跟随控制台，不自动发起播放。

后续版本准备好时，所有页面切换至该版本并暂停，点击“继续画”播放。连接失败时本页停止推进；重连后追上服务端进度。服务重启后播放保持暂停，不自动重播。当前使用约500毫秒轮询，不能保证音视频帧级同步。
