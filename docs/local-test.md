# 控制台本地测试

双击项目根目录的 `启动.cmd`，选择“本地离线测试”，浏览器会打开 `http://127.0.0.1:18080/?console=1`。命令行也可以执行：

```powershell
.\启动.cmd -Action local-test
```

这是**隔离的离线演示**：文字来自本地脚本，声音是 1.2 秒低音量提示音，不是角色语音。它复用正式控制台、WebSocket 播放归属和浏览器播放回执，可检查输入、事件显示、排队、暂停、继续、跳过、清空与打断。选择离线故障场景还可检查等待、模型失败及语音失败的提示。场景“已加入”只表示排队成功，播放成功要以浏览器真实回执为准。

进入左侧 **场景测试**，选择“普通对话”“倾听与安慰”或“礼物感谢”，可修改预览文字后点击 **运行离线场景**。需要测试故障时，选择“回复延迟”“回复失败”或“语音失败”；正在回复或播放时可用“打断当前播放”停止当前测试，再发送下一条。展开“自定义事件与模拟输入”可以注入不同来源的事件。首次播放若被浏览器拦截，请点击启用声音，之后观察顶部播放状态和场景结果。

顶部状态区会区分连接、回复、语音和播放页面。多个页面同时打开时，只有当前播放页面输出声音；连接中断后可以重新连接，页面不会重发上一条消息。重新连接会恢复进行中的回复和播放状态，刷新页面不会恢复之前的聊天记录。在正式控制台中，同一面板只会把场景填入草稿，需手动确认发送；故障场景仅在离线服务可用。

“高级设置”中的 **导出本次体验指标** 会下载带有离线标记的 JSON，只包含本次服务的统计和播放回执计数，不包含聊天正文，也不代表真实模型或语音引擎的性能。

离线服务不加载正式 `settings.yaml`、角色配置或 `.env`，不连接 B站、语言模型、语音引擎、Minecraft 或后台任务，不保存正式观众记忆。只在 `data/local-test/` 生成测试提示音；对话和队列仅存在内存，服务重启会清空。皮套和前端资源从项目中只读加载。离线页面禁用麦克风与摄像头，请用键盘输入；真实语音识别、模型能力和角色音色应在正式服务的开播演练中检查。

再次启动会检查并复用本项目已运行的离线服务；如果端口被其他程序占用，会明确报错，不结束其他程序。需要另一端口时：

```powershell
.\启动.cmd -Action local-test -Port 18081
.\启动.cmd -Action local-test -NoBrowser
.\启动.cmd -Action local-test -ValidateOnly
```

`-ValidateOnly` 只检查启动依赖与参数，不启动服务或写测试数据。也可以运行 `.\.venv\Scripts\python.exe -m brain.local_test --no-browser`。离线模式保留独立端口，拒绝使用正式服务常用的 8080、8085、9880、9890。启动器菜单及旧脚本路径迁移见 [统一启动器](launcher.md)。

结束测试时，在启动窗口按 `Ctrl+C`。正式服务不会被重启或停止。离线测试不提供投票、栏目、待答卡、记忆管理和真实开播演练的业务接口；这些功能请回到正式控制台验证。
