# 控制台体验更新（2026-09-29）

## 日常操作

- 左侧按日常对话、直播运营、本地测试、高级设置组织入口；输入区保留聊天、语音和播放操作。
- 顶部显示连接状态、配置的回复模型与语音后端，以及声音由当前页、展示页还是 OBS 页播放。模型名称只是配置信息，不代表服务已通过连通性测试。
- 浏览器拦截声音时显示启音操作；连接中断后显示重新连接。草稿在发送失败时保留，不会在重连后自动重复发送。
- 向上阅读聊天记录时，新消息不会强制滚到底部；点击新消息提示可回到最新位置。中文输入法选字期间按回车不会误发。
- 重连恢复正在生成、合成和播放的状态，清除旧连接遗留的忙碌状态。刷新网页不恢复完整聊天记录。

## 本地测试

双击项目根目录 `启动.cmd`，选择“本地离线测试”，默认打开 `http://127.0.0.1:18080/?console=1`。也可运行 `.\启动.cmd -Action local-test`。启动器使用项目的 Python 环境，重复启动复用同一项目的离线服务；端口冲突会报错，不停止其他服务。统一入口及旧路径迁移见 [启动器说明](launcher.md)。

场景面板支持普通对话、倾听与安慰、礼物感谢、打断，以及延迟、回复失败和语音失败模拟。结果提示区分请求提交、回复到达、音频派发、开始播放和播放结束；结束依据浏览器回执，不代表测量了扬声器声音。多个页面打开时会提示实际声音归属。

离线模式使用脚本回复和 1.2 秒低音量提示音，不加载正式设置或密钥，不调用模型和语音引擎，不写正式观众记忆。麦克风和正式业务入口禁用；详情、退出方法和参数见 [本地测试说明](local-test.md)。正式控制台中的普通场景只填入草稿，需手动发送；延迟与失败模拟仅用于离线服务。
