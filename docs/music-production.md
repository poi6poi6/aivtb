# 音乐制作接入状态

路线已确定：现成歌 → 原曲 → 分离人声/伴奏 → RVC转换 → 混音；原创主题 → Suno → 成品音频。

RVC本地制作流程已接入，配置模型和同名原曲后可运行；Suno已支持无需API的半自动流程，详见 suno-manual.md；RVC详见 rvc.md。

- 弹幕或聊天输入 `唱歌 歌名` / `翻唱 歌名`：记录RVC翻唱请求。
- 输入 `原创 下雨天的温柔爵士歌` / `写歌 下雨天的温柔爵士歌`：记录Suno原创请求。
- 点歌面板显示待配置原因，主播可取消请求。每位用户间隔30秒，待办最多20项，同类相同内容去重。
- 请求保存至 `data/music/requests.json`，朋友测试保存至独立测试目录。记录请求不会调用LLM假装制作，也不发起Suno付费请求。
- `点歌 歌名` 仍播放本地曲库；B站视频仍手动选择播放。

下一步需要：

1. 自备 RVC 模型路径（`.pth`、可选`.index`），及人声分离/推理环境。现有IndexTTS2声音参考文件不是RVC模型。
2. 可用原曲音频，以一首歌实测分离、转换与混音。网易云搜索/音源获取尚未接入。
3. Suno官方API账号的接口文档、认证配置位置；密钥只留在本机。公开登录页面不足以确定请求和轮询协议，不使用猜测接口或第三方冒充官方接口。
4. 完成音频制作后再连接缓存、播放队列和歌声嘴型，验证实际播放回执。

官方入口：https://platform.suno.com/ 。RVC：https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI 。
