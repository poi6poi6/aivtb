# 直播姬接入

在 `config/settings.yaml` 填写自己的直播间号并启用 `sources.bilibili_enabled`。本项目接收弹幕，直播姬负责推流。

- 控制台：http://127.0.0.1:8080/
- 直播姬浏览器素材：http://127.0.0.1:8080/?display=1
- 人物素材设置为 3840 × 2160；展示页背景透明，字幕气泡位于右上角。
- 原生 4K 素材使用 1 倍渲染，1080p 使用 2 倍，避免额外生成 8K 画布。
- 独立弹幕素材：http://127.0.0.1:8080/danmaku ，建议 800 × 1200，可单独摆放和缩放。
- 弹幕页只显示观众消息及礼物，保留本次服务最近 50 条历史，不会播放或抢占声音。
- 展示页连接时优先接管 TTS 与弹幕点歌播放，控制台停止当前音频。
- 如浏览器内核阻止声音，通过素材交互点击“启用直播声音”，再测试一条回复。
- 检查直播姬素材音频或系统声音的电平，只采集一路以避免重复。

观众发送 `点歌 歌名`，从 data/songs 内的音频匹配；唯一匹配才会加入队列。
全房间点歌间隔至少 10 秒，队列最多 10 首，重复歌曲不重复排队。
暂不支持从互联网搜索歌曲；控制台临时选择的本地文件不会共享到直播素材。
请在开播前把曲目放入 data/songs。

控制台“设置与调试”显示弹幕实际连接状态；状态来自心跳，不是配置开关。
匿名连接已验证能收到心跳，用户名可能由平台脱敏。
如需登录会话，在本机 .env 设置 BILIBILI_SESSDATA 后重启，不要公开该值。

依赖采用 blivedm 上游提交 3bf17fe862b8c2fc6bc04c81c3f0c5db95de93d6，
固定源码保存在 `vendor/blivedm`。本地兼容包版本为 `1.1.7+vtuber.1`，
只修改包版本及依赖声明；Python 源码和 MIT 许可证保留原样，并记录 SHA-256。
安装时在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-bilibili.txt
.\.venv\Scripts\python.exe -m pip check
```

兼容范围为 aiohttp `>=3.14.1,<3.15`、yarl `>=1.24.2,<1.25`、
Brotli `>=1.2.0,<1.3`，避免旧依赖声明与主程序网络库冲突。
来源及差异见 [PATCHES.txt](../vendor/blivedm/PATCHES.txt)。
