# Suno 半自动原创

不需要 Suno API。项目用现有文字模型准备文稿；Suno网页上的音色选择、生成、试听和下载由主播完成。

1. 弹幕或聊天发送 `原创 下雨天的温柔情歌`（也支持 `写歌 主题`）。
2. 控制台打开“点歌”，找到Suno原创任务。文字模型自动准备标题、风格和歌词；失败可重试，也可以手动填写。
3. 展开任务，编辑并保存文稿，分别点击“复制标题／风格／歌词”。打开Suno，在网页中选择自己的声音档案并粘贴，手动生成。
4. 试听选中版本后下载。把文件放到项目 `data/music/suno-inbox`。支持MP3、WAV、FLAC、M4A、OGG，单文件上限150MB。
5. 下载列表在展开面板时每5秒刷新；首次看到新文件后需稳定至少3秒才显示。选择该任务对应文件，点击“确认此文件并入队”。
6. 项目通过FFmpeg完整解码为WAV，成功后保存至曲库、绑定任务并发送到唯一播放页面。源文件保留。以后可点“播放成品”，或用相同原创主题触发缓存点播。

成品已导入不代表浏览器已开始播放。浏览器音频权限、当前播放队列仍按原有播放器处理。导入失败不会产生播放请求。

草稿和任务保存在 `data/music/requests.json`，重启保留。停止或取消准备中的任务，不会虚构音频生成成功。朋友测试不自动准备文稿，也不能访问下载目录或执行导入。

项目不自动登录Suno、不自动点击Create、不代做身份验证。无需Suno密钥，但自动写歌词仍使用本机已有的文字模型配置。
