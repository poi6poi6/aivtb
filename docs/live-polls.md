# 栏目投票（2026-09-22）

主控新增「栏目投票」入口，地址为 `http://127.0.0.1:8080/polls`。修改后重启主控并刷新网页生效；这项功能不依赖后台任务服务或外部模型生成票数。

## 使用流程

1. 打开栏目投票页，选择一个投票模板，或填写自定义栏目。
2. 写好问题和 2–6 个选项，每行一个；时长可设为 15–3600 秒。正式参与方式为「B站弹幕」。一次只开启一轮。
3. 点击「开始投票」。观众发送 `投票 1`、`投票 A` 或 `投票 雪`，编号、字母和选项全称均可；单独发送 `1` 或 `雪` 不算投票。
4. 可以点击「播报规则 / 结果」，把当前规则或已结束的实际结果加入她的语音队列。使用现有主控的 TTS 和播放器，投票页自身不播放音频。不会逐票打断她。
5. 倒计时到期后停止收票，也可点击「结束并统计」。最高票相同会显示并列，无人参与不会选出结果；「取消本轮」保留票数记录，但不选出结果。

模板只填入待编辑的问题，不会自动启动绘画、游戏或其他任务。最终选中什么、是否继续执行，由主播决定。

## 计票口径

- 在弹幕进入注意力筛选、回复冷却与语言模型前处理投票；她是否读出某条弹幕不影响计票。
- 正式票仅接受真实 B 站弹幕中的稳定账号标识（UID 或现有适配器提供的账号哈希）。同名的不同账号分别计票；同一账号始终一票，再次选择会改票。
- 无账号标识、临时随机身份、普通文字聊天、模拟弹幕、礼物消息均不计入正式票。缺少账号身份时不会按昵称猜测合并。
- 计票以主控实际处理有效弹幕的时间为准。开始前已进入队列的旧消息、截止后处理的消息、较旧的同账号消息不会改动结果；平台连接中断期间未收到的消息不会补造。
- 票数和截止时间保存在 `data/live-polls.sqlite3`。主控或页面重启后继续读取；已过期的投票会自动结束。运行中主控每秒检查截止时间，页面每秒刷新统计。
- 数据库保存按每轮随机盐计算的账号摘要，不存原始 UID、昵称或弹幕正文；页面只返回汇总结果。历史面板显示最近 20 轮，数据库保留此前记录。

## 本机演练与 OBS

选择「测试 · 本机模拟」开一轮测试，页面会出现测试名字和选项编号输入框。同一个测试名字可以改票。测试轮明确标记为「测试投票」，不会接收直播观众票，也不会混入正式轮。

OBS 浏览器源使用 `http://127.0.0.1:8080/polls?clean=1`，建议宽 720、高 900。该页透明背景、隐藏管理表单，只展示当前一轮的题目、票数、倒计时和结果。需与主控在同一电脑使用。

断线时页面标记「最后一次统计」，停止显示倒计时变化，主控按钮不可操作；重连后读取最新状态。投票使用主控时间，不依赖 OBS 或浏览器的时钟。播报按钮按点击时生成内容，已加入队列不等于已经出声；规则播报不读可能因排队而过期的剩余秒数。
